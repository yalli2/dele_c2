# DELE C2 대비 학습실

국제학교 스페인어 DELE C2 시험대비 수업용 인터랙티브 사이트입니다.

- 모의시험 6회분 (어휘·독해 26문항, 듣기 26문항, 통합 쓰기 3과제, 통합 말하기 3과제), 6회는 해설(pautas) 포함
- 독해·듣기 문항은 바로 풀고 채점 (점수·해설 표시, 브라우저에 기록 저장)
- 듣기: 원어민 음성(브라우저 TTS, Edge의 Natural 음성 권장) — 남녀 목소리로 강연·토론·인터뷰 재생
- 쓰기: 강연+자료 종합 보고서, 장르 전환, 그래프 분석 — 단어 수 자동 계산, 자기 점검표, 모범답안
- 말하기: 자료 발표(준비 30분 타이머), 녹음 후 다시 듣기, 면접관 질문 음성, 모범 발표

참고 교재: 『Preparación al Diploma de Español, Nivel C2』(Edelsa)의 시험 구성과 주제.
지문·문항·듣기 스크립트는 저작권 보호를 위해 수업용으로 새로 작성·각색했습니다.
